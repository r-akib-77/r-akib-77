# `06 / THE HARD PART`

<div align="center">

<img src="https://readme-typing-svg.demolab.com?font=JetBrains+Mono&size=17&pause=1000&color=F472B6&center=true&vCenter=true&width=800&lines=THE+FEATURE+IS+ONLY+THE+BEGINNING.;PRODUCTION+IS+WHERE+ENGINEERING+STARTS."/>

</div>

<table>
<tr>
<td>

### `01` Race Conditions

Concurrent requests can turn correct business logic into incorrect state.

**Solution mindset**

```text
Validate
 ↓
Atomic operation
 ↓
State transition
 ↓
Persist
 ↓
Emit event
```

</td>

<td>

### `02` Payment Reliability

A webhook can arrive twice.

The system should still record the transaction once.

```text
Webhook
 ↓
Verify
 ↓
Idempotency
 ↓
Transaction
 ↓
Commit
```

</td>
</tr>

<tr>
<td>

### `03` Email Deliverability

SMTP isn't just:

```text
send(email)
```

Production email requires:

```text
SPF
DKIM
DMARC
Warmup
Reputation
Queues
Segmentation
```

</td>

<td>

### `04` Signed Updates

Desktop software introduces a trust chain.

```text
BUILD
 ↓
SIGN
 ↓
PUBLISH
 ↓
VERIFY
 ↓
INSTALL
 ↓
ROLLBACK
```

</td>
</tr>
</table>
